# telelem

telelem is a proposed Elixir/OTP gateway for LLM requests. Its first goal is to let a developer run their own SDK against two local deployments, interrupt a stream, and see exactly what the gateway did and what the client received.

**Status: M1 experiment in verification.** [Rerun the real-SDK experiment](docs/m1-results.md) to see when the backup is used and when switching would be incorrect. The [engineering roadmap](docs/roadmap.md) tracks the work beyond the experiment.
